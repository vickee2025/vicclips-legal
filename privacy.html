Privacy Policy — VicClip Publisher

Effective Date: November 26, 2026

VicClip Publisher is a private content-publishing and archival automation tool operated by the owner of @VicClipsGTA (vickee2025@gmail.com).

1. Information Accessed

When authorized by the account owner via Google OAuth 2.0, the application accesses only the permissions explicitly granted:

  • YouTube Data API v3: Uploading scheduled short-form videos and reading channel identity for the authorized Brand Account.
  • Google Drive API v3 (drive.file): Archiving published media files created or uploaded by this tool into dedicated archive folders.

2. How Data Is Used & Stored

OAuth credentials are stored encrypted exclusively for the owner's automated publishing and backup workflows. No user data is sold, shared with third parties, or used for advertising.

3. Revocation & Contact

Access can be revoked anytime via Google Account Permissions. Questions: vickee2025@gmail.com.
